# Visual design

These are defaults when the user and project leave choices open:

- Keep visuals clean and focused. Use whitespace rather than decorative cards,
  borders, shadows, or background boxes unless a boundary encodes information.
- Prefer earth tones while preserving semantic color mappings, sufficient
  contrast, and readability for people with color vision deficiencies. Do not
  use color as the only way to distinguish an essential category or state.
- Use light backgrounds for publications and presentations. Prefer dark mode
  for interactive work, with a light alternative when the delivery format allows.
- Prefer SVG for simple static graphics, PDF when required for publication,
  and PNG for inherently raster images or very dense graphics, roughly over
  100,000 elements. Match the requested export format and target medium.
- Set export dimensions explicitly. Inspect the actual render at its intended
  size for clipping, text collisions, line weight, and legibility. For responsive
  output, also inspect a narrower layout and each supported theme.
- Supply meaningful alt text or a nearby text explanation. Keep labels and
  captions concise, with units and definitions where needed.
