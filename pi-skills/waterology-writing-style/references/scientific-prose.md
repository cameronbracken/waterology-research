# Scientific Prose

Use this layer for manuscripts, abstracts, reports, captions, technical
findings, and research summaries. Apply these general research-writing checks alongside the
project requirements and optional local writing guidance.

## Argument shape

1. Establish the practical or scientific problem.
2. Narrow to the missing dataset, definition, benchmark, or analysis.
3. State the contribution with an active first-person plural verb when
   appropriate: `we examine`, `we present`, `we use`, `we define`, or `we find`.
4. Give the evidence before interpreting it.
5. End with the scientific or operational consequence.

For abstracts, a useful sequence is context, gap, approach, quantitative
result, limitation, and implication. Do not add explicit subheadings unless
the target format calls for them.

## Scope and evidence

- Define the period, spatial extent, resolution, threshold, dataset,
  infrastructure assumptions, and sample size early.
- Explain methods in operational order. Name data sources, models, calibration
  and validation periods, metrics, and consequential parameter choices.
- Organize results around scale, season, geography, and operational meaning.
- Use concrete comparisons and measured quantities before broader claims.
- Separate observation, possible mechanism, and implication. Use `may`,
  `likely`, `suggests`, or `indicates` when causality or generality is uncertain.
- State limitations directly. Distinguish resource availability, modeled
  behavior, and observed system operations.
- Include data, code, environment, and provenance details that support reuse.

## Revision checks

- Reduce repeated openings such as "In this study."
- Shorten long clause chains and replace nominalizations with direct verbs.
- Use one term, capitalization, and hyphenation pattern for each concept.
- Reject `first` and `first of its kind` unless the literature review supports
  the claim.
- Check affect/effect, articles, agreement, and typographical errors.
- Use numbered research questions only when they clarify scope.

## Optional style corpus

The `writing.papers` list in the local Waterology configuration supplies optional
DOIs, URLs, or paths to example papers. `writing.files` can hold the user's
analysis of those examples. No corpus is bundled as a personal style default.
Source papers can be collaborative and publisher edited. Treat a selected
corpus as examples, not proof of a single author's voice.
