# Waterology 0.8.2

This release consolidates reusable preferences into opinionated package skills
while keeping private context in local configuration.

- Add focused entry points for data visualizations, conceptual diagrams,
  reports, simple Markdown notes, code documentation, and R style.
- Add interactive graphics and report layers that load only for requested
  interaction. Keep shared visual design and Markdown delivery in small references.
- Consolidate tool choices, environment defaults, prose conventions, public
  scientific writing examples, and blog recipes into canonical skills and rules.
- Document the boundary between public package defaults and private values,
  machine context, identity, account settings, and local overrides.
- Enable implicit invocation for the primary entry points and document ordinary
  prompt examples. Explicit skill commands remain optional.
- Fix Pi generation so relative cross-skill links point to the namespaced
  generated skill folders, with a regression test for link resolution.

See [artifact skills](../artifact-skills.md) and
[personal configuration](../local-configuration.md) for routing and migration.
