# Waterology 1.0.1

Waterology 1.0.1 separates formal peer-reviewed scientific manuscript writing from general conversational technical prose and updates `writing-style` for lower token overhead.

## Highlights

- **Dedicated scientific manuscript skills (`scientific-writing` and `scientific-writing-detailed`):** Added corpus-grounded guidance for peer-reviewed journal articles, methodological/Bayesian frameworks, and data descriptors covering operational framing, candid null and approximation reporting, calibrated epistemic hedges, ~20-word academic sentence cadence, grammatical equations, and self-orienting figure narration. Both variants carry explicit mutual-exclusion rules so at most one is loaded per session during A/B evaluation.
- **Refocused `writing-style` for non-paper prose:** Removed `references/scientific-prose.md` and updated `writing-style` to a compact single-file skill with a conversational-technical default (explanations, blog posts, walkthroughs, notes, emails) alongside a direct reference/status register (READMEs, docs, reports, plans, PRs, commits).
- **Updated manuscript routing:** Pointed `research-review`, `literature-review`, `reports`, `rules/quarto-conventions.md`, and the `reviewer` subagent to `scientific-writing` for formal paper work while preserving `writing-style` for general report prose and Markdown delivery.
