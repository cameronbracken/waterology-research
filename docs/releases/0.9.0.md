# Waterology 0.9.0

This release adds Antigravity runtime support across agent rendering, asset
installation, diagnostics, MCP registration, and supervised agent sessions.

- Generate Antigravity subagent definitions under `.agent/agents/*.md` with
  YAML tool lists mapped from canonical agent capabilities.
- Add `waterology install antigravity` and `waterology uninstall antigravity`
  for project scope (`.agent/skills/`, `.agent/agents/`) and user scope
  (`~/.gemini/config/skills/`, `~/.gemini/config/agents/`).
- Add `agy` runtime checks to `waterology doctor` and MCP configuration output
  to `waterology mcp config antigravity`.
- Add `AntigravityAdapter` for supervised `agy -p` stream-json sessions, native
  `--conversation` resume, and bounded study candidate generation.
