# Waterology 1.0.0

Waterology 1.0.0 refocuses the package on consistent research output, tool and visualization conventions, deterministic verifiers, and low-overhead reference and dataset tooling.

## Highlights

- **80% smaller MCP surface (`waterology-mcp`):** Trimmed from 56 tools (~6,250 eager schema tokens) to 10 bounded tools (~1,300 tokens) covering 11 scholarly search providers (`openalex`, `semantic-scholar`, `core`, `alphaxiv`, `alphaxiv-keyword`, `arxiv`, `pubmed`, `europepmc`, `biorxiv`, `medrxiv`, `crossref`), standalone `.zotero.toml` sync with local PDF caching, and Hugging Face Hub inspection (`hf_dataset_info`, `hf_repo_files`, `hf_repo_read_file`).
- **Standalone `.zotero.toml`:** `wgy zotero init` now works in any repository or paper directory without `waterology.toml`. Outside `.zotero.toml` workspaces, `wgy discover` runs cleanly in memory (`recorded: false`).
- **Zero `config context` shell round-trips:** Removed subprocess activation calls across all skills and rules, eliminating 1 to 3 extra LLM turns per task.
- **Consolidated catalog (40 -> 17 skills, 11 -> 3 agents):**
  - Merged `data-visualization`, `figure-style`, `figure-composer`, and `interactive-graphics` into `figures` with unified earth-tone palette guidance.
  - Merged `deep-research` and `ml-training-recipe` into `literature-review` without `.plans/` or `.drafts/` multi-rewrite churn.
  - Merged `paper-code-audit` and `pipeline-manifest` into `audit-reproducibility`, `interactive-reports` into `reports` (removing domain-specific reservoir text), `paper-narrative` into `research-review`, and `capture-environment` into `setup-environment`.
  - Simplified subagents to `researcher`, `reviewer`, and `engineer`.
- **Retired `.waterology/` execution database:** Removed the custom experiment/archive/RO-Crate/SQLite/TORC-wrapper/study-controller/session-supervisor/dashboard/learning runtime (~14,000 LOC) in favor of Git + lockfiles + lightweight `autoresearch` (`results.yaml`) + native `torc` when distributed or HPC execution is needed.
