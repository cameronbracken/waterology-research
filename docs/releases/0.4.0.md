# Waterology 0.4.0

This release adds managed research and engineering studies with bounded TORC
execution, candidate sessions, durable resume, comparisons, and claim assessment.

- Add literature records, portable Quarto report bundles, and dashboard study views.
- Add evidence-backed project lessons, NestedText contracts, and optional Pyzotero
  reference and PDF synchronization.
- Bind claim assessments to the reviewed content. Editing a claim invalidates its
  prior assessment. Legacy assessments without a fingerprint require fresh review.
- Add a roadmap TODO for a complete documentation site with runnable examples.

Qualification remains limited for remote TORC, real unattended model generation,
native Windows/Linux execution, and authenticated Zotero writes and PDF uploads.
See the managed workflow and ECC/Zotero records in `docs/validation/`.

Validation: 544 tests passed. Ruff, generated runtime checks, all eight repository
constraints, and wheel/source builds passed. Release review found and fixed the
claim assessment issue with four regression tests.
