# Waterology 0.8.1

This release adds a `sol-pi` skill that hands coding tasks to
[SoL-Pi](https://github.com/NVlabs/SoL-Pi), a token-efficient agent built on Pi.

- Add `skills/sol-pi`, merged from the upstream Claude Code and Codex skills.
  It hands off the current prompt with the conversation as context, or
  delegates a self-contained subtask, then reports SoL-Pi's changes and cost.
- The skill needs the upstream `sol-pi-run` launcher on PATH. The launchers and
  optional prompt hooks stay in the SoL-Pi checkout and are not bundled.
- Credit NVlabs/SoL-Pi (MIT) in `ATTRIBUTION.md`.
