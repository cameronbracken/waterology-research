# Waterology 0.9.1

This release makes TikZ flowcharts and standalone Markdown report bundles the
Waterology defaults for conceptual diagrams and reporting.

- Update `diagrams` to use Earth-Tone 7-role TikZ flowcharts by default,
  bundling `resources/flowchart-tikz.sty`, `scripts/check_tikz_svg.py`, and
  `references/integration-patterns.md` for geometry verification and Light/Dark
  theme SVG integration.
- Update `reports` to produce self-contained, portable Markdown report bundles
  (`reports/<topic>-<YYYY-MM-DD>/`) by default, bundling
  `resources/report_template.md`, `resources/earth_tone_plot_template.R`, and
  `scripts/verify_report_bundle.py`.
- Align `project-conventions`, `rules/quarto-conventions.md`, and
  `docs/artifact-skills.md` with the new diagram and report defaults.
